# ربط الموقع الثابت بخدمة البلاغات

بُني الموقع الثابت بحيث لا يحتوي أي سر أو مفتاح. بعد نشر خدمة **Mafkoudin DZ Admin**، انسخ أساس رابطها العام فقط إلى المتغير في `js/api-config.js`:

```js
window.MAFKOUDIN_REPORTS_API_BASE_URL = "https://YOUR-PUBLISHED-ADMIN-DOMAIN";
```

لا تضف لاحقة `/api` إلى الرابط. بعد رفع التعديل إلى GitHub Pages، يستقبل `pages/report.html` البلاغات في `POST /api/public/reports`، بينما تدمج الصفحة الرئيسية وصفحات التفاصيل البلاغات ذات الحالة `approved` فقط من `GET /api/public/reports`.

تتصل الواجهة العامة بخدمة خلفية تسمح حصريًا بمصدر GitHub Pages للإنتاج، ولا ترسل سوى الحقول العامة إلى صفحات الزوار. تبقى بيانات المبلّغ في قاعدة البيانات ولا ترجعها واجهة العرض العامة.
